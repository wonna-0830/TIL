## 📝 문제 요약
> 프로그래머스 모바일은 개인정보 보호를 위해 고지서를 보낼 때 고객들의 전화번호의 일부를 가립니다.
> 전화번호가 문자열 phone_number로 주어졌을 때, 전화번호의 뒷 4자리를 제외한 나머지 숫자를 전부 *으로 가린 문자열을 리턴하는 함수, solution을 완성해주세요.

## 💡 풀이 아이디어 
- 문자열을 배열로 하나씩 인덱스에 넣고, for문을 이용해 마지막 4자리 전까지만 순회하면서 *로 수정

## 🧩 구현 코드
```java
import java.util.*;
class Solution {
    public String solution(String phone_number) {
        String answer = "";
        String[] arr = phone_number.split("");
        for(int i = 0; i < arr.length - 4; i++){
            arr[i] = "*";
        }
        answer = String.join("", arr);
        return answer;
    }
}
```

```kotlin
class Solution {
    fun solution(phone_number: String): String {
        var answer = ""
        val arr = phone_number.split("").toTypedArray()
        for(i in 1 until arr.size - 5){
            arr[i] = "*"
        }
        answer = arr.joinToString("")
        return answer
    }
}
```

## ⚠️ 실수/배운 점
- 오늘은 어렵진 않았다.
- 대신 코틀린에서 for문 증감식 정하는데 조금 애먹었다.
- `i in 0 until arr.size - 4`로 하니까 *가 하나 더 늘어나고 3자리까지 숫자가 살아있었다.
- 그래도 이건 수정을 하면서 바로 고쳤다.

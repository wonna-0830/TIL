## 📝 문제 요약
> 단어 s의 가운데 글자를 반환하는 함수, solution을 만들어 보세요. 단어의 길이가 짝수라면 가운데 두글자를 반환하면 됩니다.

## 💡 풀이 아이디어 
- 문자열을 배열로 만든 다음 if로 배열 길이가 짝수인지 홀수인지 판별
- index에 배열길이의 절반 값을 대입해서 짝수 홀수에 따라 연산을 넣어 인덱스 추출

## 🧩 구현 코드
```java
import java.util.*;
class Solution {
    public String solution(String s) {
        String answer = "";
        String[] arr = s.split("");
        int len = arr.length;
        int index = len / 2;
        if(len % 2 == 1){
            answer = arr[index];
        } else {
            answer = arr[index - 1] + arr[index];
        }
        return answer;
    }
}
```

```kotlin
class Solution {
    fun solution(s: String): String {
        var answer = ""
        val arr = s.split("").toTypedArray()
        var len = arr.size
        var index : Int = len / 2
        if(len % 2 == 1){
            answer = arr[index]
        } else {
            answer = arr[index - 1] + arr[index]
        }
        return answer
    }
}
```

- 보니까 int 타입끼리의 연산은 소수점이 나오더라도 버려진다고 한다!!!
